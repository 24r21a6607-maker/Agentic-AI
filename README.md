## 📌 Project Overview
**Placements - Ready AI Agent 6465** is a Career Coach AI Agent designed to solve the challenges students face during campus placement preparation. It provides interactive interview simulations, technical/HR question sets, aptitude prep, and real-time placement readiness scoring.

---

## 🚀 Features
- **Interactive Interview Simulation:** Generates custom company-specific HR and technical interview questions (e.g., TCS, Infosys, Wipro).
- **Placement Readiness Scoring:** Evaluates candidate responses and provides readiness scores out of 100.
- **Multi-Model Support:** Integrates with OpenAI models (`gpt-4o`, `gpt-4-turbo`, `gpt-3.5-turbo`).
- **Conversational UI:** Built using Streamlit for an intuitive chat interface.

---

## 🛠️ Tech Stack & Specifications
- **Framework:** Custom BaseAgent Logic / Streamlit
- **Language:** Python 3.10+
- **APIs / SDK:** OpenAI API (`OPENAI_API_KEY`)
- **Key Tools:** `MonitoringClient`, `BaseAgent`
- **Target Users:** Placement Cells & Final-year Students
